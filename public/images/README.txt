Default Images Needed
===================

This directory should contain default placeholder images for musicians who haven't uploaded custom images.

Required files:
- default-avatar.png (128x128px or larger, square)
- default-banner.png (1200x400px or larger, 3:1 aspect ratio)

Recommendations:
- Use simple, professional-looking placeholder images
- Avatar: Use a generic music-related icon or silhouette
- Banner: Use a subtle gradient or music-themed background
- Keep file sizes small (< 100KB each) for fast loading

You can create these images using:
- Design tools: Figma, Canva, Photoshop
- Icon libraries: Font Awesome, Material Icons
- AI image generators: DALL-E, Midjourney
- Free stock photos: Unsplash, Pexels

Temporary solution:
Until you add these images, you can:
1. Use any placeholder image service (e.g., https://via.placeholder.com/128 for avatar)
2. Update the paths in musicians/config.json to point to online placeholders
3. Or temporarily use solid color backgrounds as placeholders
